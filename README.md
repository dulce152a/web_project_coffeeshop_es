# Coffee Shop Landing Page

Proyecto de landing page para una cafetería.

## Estructura

- `images/` para archivos de imágenes e iconos.
- `styles/` para estilos CSS.
- `fonts/` para fuentes personalizadas.
- `index.html` archivo principal.

## Cómo abrirlo

Abre `index.html` en el navegador para ver la página.
